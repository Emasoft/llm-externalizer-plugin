## Approved plan 2026-11-04

Plan approved by the user (ExitPlanMode) on 2026-11-04. Decision: code splits sentences (Intl.Segmenter rejected, it merges lowercase-started sentences); Jev scores each sentence with one noul question and decides grouping with one join question per adjacent pair, both in one call; requirement text is the verbatim concatenation of the group (no rewrite, so no LLM in C1).
