USER directive verbatim (2026-10-28, replaces the router-mode answer and the Locals exception): "wait.. one server per model, exactly.. but only one model type must run at any time. the others must be enqueued in a smart way. even in case of ensemble. if 10 ensemble scan commands arrive at the same time, you don't start 3 servers x 10 = 30 servers! Consequence: the one-model-at-a-time batching applies to local engines only (remote profiles unchanged); the batch size before a rotation and the maximum wait of other models are calibrated, and queued requests never time out while waiting.
